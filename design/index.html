04 Design tokens

What carries into SwiftUI

Typography

14:41300 · −4.8%

SF Pro Display for time, SF Pro Text for labels. Tabular numerals so minutes never shift the layout.

Palette

Ink / primary text
Ink 2 / city, dates
Ink 3 / offsets, meta
Hairline / 1 pt dividers

Geometry

2×2 158×158 · 4×2 338×158 · 4×4 338×338 pt.

Continuous corners at 13% of tile width; 7.5% on 4×4. Padding 20–24 pt. Never circles.

Behavior

Minute refresh via timeline entries aligned to the minute.

Context — “Tomorrow” replaces the weekday when the day differs. Offsets use UTC±h[:mm].
